On-demand worksheets and examples
Each four-pillar example has a Configuration button. It opens the proposed
sub-agent, actions, data sources/objects, instructions, inputs/outputs and
tests without changing the current core slide. Return to deck closes it.
The worksheet has its own Notes and Edit design controls.

More > Worksheets & examples opens all 12 worksheets:
  Four agent configuration sheets; the additional transcript example;
  data/object/retriever details; value measurement notes; UX decisions;
  operating requirements; agent boundaries; service handoff; extra notes.
Use the worksheet selector to switch between them. Configuration and
Conversation buttons link each example to its configuration sheet.

Slide 6 opens the full-screen scripted conversation view. Walk through on
an example does the same. Show next turn reveals the conversation;
Replay example restarts it. Edit this example returns to its editable
slide or worksheet. These are discussion examples, not a live agent.

Audience, scope and assumptions
The agent serves Prospective Student / Learner, Applicant, Student and
Alumnus. Confirm sign-in routes, NUS-ID eligibility and content permissions
with NUS for every audience. The alumnus sign-in conversation is one
illustration, not a complete access policy.

Slide 3 states delivery of the agreed Builder scope and a working agent
in the NUS HUB full-copy sandbox, plus handover and support moving to
production. NUS and delivery partners own rollout, testing and operations.

Slide 5 uses editable percentage hypotheses, not NUS results or benchmarks.
Agree baselines, denominators, measurement windows and targets with NUS.
Slide 15 is an illustrative four-week Gantt aiming for late Dec / early Jan.
Use Notes to edit W1–W4 ranges, such as W2 → W3. Exact dates, capacity and
release conditions remain to agree. Unconfirmed decisions stay To confirm.

Workshop notes and compatibility
All 174 fields from the previous review version are preserved. New source
access/owner fields and readiness statuses bring the total to 189.
Earlier notes import into the corresponding topic, including worksheets.
Slide numbers have changed; old bookmarks may point to a different topic.
The earlier enquiry/hour calculator fields remain retired and are not
mapped to the percentage matrix.

Edits are stored in this browser; they do not change GitHub, the original
HTML file or other viewers' copies. More > Export notes & design saves JSON.
More > Save HTML with notes creates a self-contained copy with your inputs.
Use export/import to move inputs between local and hosted copies.
Shared HTML snapshots keep their later browser edits separate from other
copies. Keep field entries concise when presenting; Read all slides shows
longer core notes, and worksheets allow longer configuration entries.

Print / Save PDF includes the 18 core slides only. Enable background
graphics and check the browser print preview before sharing. Worksheets
and their notes remain available in HTML and JSON exports.
