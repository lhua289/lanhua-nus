NUS HUB × Salesforce Agentforce — Builder Project Hub

Open index.html to enter the portal. It links to three presentations:

1. Discovery Workshop — kickoff/index.html
   The approved 18-core-slide Phase 0 deck. Includes business impact,
   delivery scope, four-week Gantt and the existing on-demand worksheets.

2. Use Case Design — design/index.html
   Eight slides, starting with the Pre / During / Post swimlane adapted
   from the Eurokars template. It contains a proposed Agent Blueprint,
   source/action mapping and admissions, FAQ, access and service-support
   examples. Configuration sheets and a transcript example open on demand.
   The design is illustrative and must be validated with NUS.

3. Build & Handover — build-review/index.html
   Six slides for a future delivery walkthrough: scope, sandbox demo,
   actual configuration, test evidence and production handover. Completion
   and test results are To confirm until evidence is captured.

All four NUS HUB audiences are in scope: Prospective Student / Learner,
Applicant, Student and Alumnus. NUS-ID eligibility, sign-in routes and
content permissions must be agreed for each audience. The sign-in example
illustrates an alumnus journey, not the complete access policy.

Presentation controls
  Portal: return to the project hub
  Left / Right arrows: navigate the current presentation
  Slides / S: choose a slide
  Notes / E: edit decisions and To confirm fields
  Edit design / D: edit design examples and configuration worksheets
  Present: browser full screen
  Pause motion: stop animations, where available
  More: worksheets, reading view, export/import, save HTML and print/PDF

Configuration opens the related settings: sub-agent, actions, data,
instructions, input/output contract and tests. The worksheet selector lets
you open another sheet. Return to deck preserves your core slide position.
Walk through opens a scripted conversation; it is not a live agent.

Each presentation saves its notes separately in the current browser.
Edits do not change GitHub, the original file or other viewers' copies.
Use Export notes & design to save JSON, or Save HTML with notes for a
self-contained copy. Import notes into the presentation that exported
them. Design edits in Discovery and Use Case Design are separate working
records; reconcile them when agreeing the Agent Blueprint.

Existing hosted discovery notes keep their original storage key. Old
root-level #slide-N links redirect to the discovery presentation. Local
file and hosted-site browser storage are separate; use export/import to
transfer inputs. The original standalone local discovery HTML is retained
outside this portal package.

Each presentation is self-contained. The portal requires its assets folder;
keep the directory structure when copying the portal. No installation or
server is needed to open these HTML files locally.

Print / Save PDF includes the core slides of the selected presentation.
Worksheets remain in HTML and JSON exports. Enable background graphics
and check the browser print preview before sharing.

Builder delivers the agreed scope and a working agent in the NUS full-copy
sandbox, then hands over and supports the move to production. NUS and
delivery partners own project delivery, approvals, content/environments,
integrations, rollout, testing and operations.
