02 / Agent design · Configuration

Configure · Admissions guidance

Proposed configuration · Validate in the NUS full-copy sandbox01 · Discovery context ↗
Sub-agent
Learner FAQ Guidance Clarify the programme and qualification route before retrieving guidance.
Actions
Answer Questions with Knowledge Candidate standard action after clarification.
Data sources / objects
Approved admissions FAQ + qualification-specific application guide. No application record required for general guidance.
Instructions & controls
Clarify study level + qualification → retrieve the matching approved guide → cite. Do not infer eligibility, admission outcomes or personal application status.
Inputs → outputs
IN: question + clarified application route OUT: grounded guidance + source. Self-declared context does not grant restricted access.
Acceptance checks
Prospective learner / applicant · ambiguous route · mismatched guide · expired source · personal status request

02 / Agent design · Configuration

Configure · Continue to service support

Proposed configuration · Validate in the NUS full-copy sandbox01 · Discovery context ↗
Sub-agent
Learner Support Routing Unresolved questions → existing NUS service route.
Actions
Baseline: Ask a Question link. Optional Flow: Create Learner Service Case (illustrative name; scope to agree).
Data sources / objects
Routing guide + form link. Optional Case: Subject, Description, verified ContactId. Inspect RecordTypeId, Origin and routing rules.
Instructions & controls
Explain the gap → offer the route. For a write: review details → obtain confirmation → report success only after execution.
Inputs → outputs
Optional IN: summary + required fields + verified contact OUT: actual Case Id / CaseNumber, or handled error.
Acceptance checks
Route · cancel · missing fields · failure · duplicate submission. Live transfer and record updates are not committed.
